# Post-Feature Documentation & Skill Update Policy

Whenever a coding task, feature implementation, or architectural change is completed:
1. Proactively identify all documentation (`docs/lld/`, `docs/plans/`, `docs/architecture/`) and skills (`.agents/skills/`) that relate to the changes.
2. Ask the user for confirmation to update the relevant documentation and skills with a clear summary of proposed documentation updates.
3. Upon user confirmation, update all relevant files to keep project documentation and agent skills 100% in sync with the codebase.
